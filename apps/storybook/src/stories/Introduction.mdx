# Counting Rods

Stories for [`@counting-rods/core`](https://www.npmjs.com/package/@counting-rods/core), which renders any number as [Chinese counting rod numerals](https://en.wikipedia.org/wiki/Counting_rods) in SVG.

- **Number Builder**: type any number in the `value` control and adjust every `toSvg` option.
- **Digits**: every digit from 0 to 9.

Places alternate between upright rods (units, hundreds) and flat rods (tens, thousands). Zero is a circle or a gap, a dot marks the decimal point, and negatives get a diagonal rod across the last digit, or black rods with `traditionalColors`.

For downloads and shareable links, use the [playground](../playground/) in the docs.
